# powerbi-sales-dashboard
Power BI Sales Dashboard using SQL, Excel and Power BI


Power BI Sales & MTD Dashboard

📊 Project Overview :

This project is an interactive Sales Dashboard built in Microsoft
Power BI.
The report is designed to monitor sales performance, transaction
activity, quantity, and month-to-date (MTD) performance through
interactive visuals and filters.

The Power BI report contains the following pages:

Dashboard --- Main sales dashboard

MTD REPORT --- Month-to-date sales analysis

Duplicate of MTD REPORT --- Additional working/reporting page

🖥️ Dashboard :

The report uses a combination of KPI cards, charts, slicers, maps,
images, and interactive controls to present business information in an
easy-to-understand format.

Main Visuals Used

KPI / Card visuals

Bar charts

Column charts

Line chart

Area chart

Pie charts

Funnel chart

Azure Map

Slicers

Interactive buttons

Custom images and design elements

📈 Key Metrics:

The dashboard focuses on important sales metrics including:

Total Transactions

Total Sales / Revenue

Total Quantity

Average / performance-related metrics

Month-to-Date (MTD) performance

🗓️ Interactive Filtering :

The report includes date-based filtering using a custom calendar/date
hierarchy.
Users can filter the report by month to analyze sales performance for a
selected period.

🛠️ Tools & Technologies :

Microsoft Power BI Desktop

Power Query --- Data cleaning and transformation

🧹 Data Preparation :

Preparing data for visualization
